## 2. 关键许可事实（必须如实对待）

### 2.1 SpriteCollab 的"两层许可"——不能一概而论

仓库 `LICENSE.md` 是完整 CC BY-NC 4.0 文本，README 要求"非商业 + 署名"。但每个物种目录下的
`credits.txt`（tab 分隔：日期 / 作者 / 当前或旧版 / 许可 / 动作项）显示：**官方 PMD 游戏拆包件的
作者署名是 CHUNSOFT、许可标注 Unspecified**——例如 `sprite/0025/credits.txt` 的 Walk/Attack 等基础动作。
据其 tracker.json，**Gen1 全部 151 只的基础精灵主署名都是 CHUNSOFT**（全库 965 只中有 492 只）。
**CC BY-NC 只覆盖社区自制件，拆包件的版权仍属 Spike Chunsoft / 任天堂系。**
本作首发名单几乎全是 Gen1，等于主体素材都是官方拆包件。

> **本项目的立场**：与使用 PokeAPI 立绘相同——"社区多年公开分发、非商业同人惯例使用、
> 收到通知即下架"。这不是法理洗白，是风险自查后的明知选择；我们在页面与仓库如实署名
> CHUNSOFT 与各物种/动作的社区作者，不做任何来源误导。

### 2.2 PokeAPI 叫声的两个坑

1. **只有 ogg**（latest/legacy 两轨），没有 mp3；
2. **`latest/25.ogg`（皮卡丘）实际是 MP3 数据**（0xFFFB 帧头、48kHz 单声道，却标成 audio/ogg）——
   解码必须 fail-soft：`decodeAudioData` 抛错就静默跳过该叫声。皮卡丘是初始角色，
   M1 就要在真机上验证这条降级路径。

### 2.3 Safari 与 ogg

Safari **18.4（2025-03）起**才支持 Ogg Vorbis/Opus 解码，而且绑定系统版本（macOS Sequoia 15.4+ /
iOS 18.4+；旧系统装新 Safari 也没有）。策略沿用像素版：解码失败静默降级，只影响叫声不影响玩法，
页脚注明"建议用 Chrome/Edge 获得完整音频"。

### 2.4 图块只用 CC0

环境贴图**完全避开官方素材**（官方图块是任天堂的直接资产）。上表 CC0 图块大多是 16×16，
正好匹配 16 texel/unit 的密度体系（DCSS 的 32×32 当作 2×2 单位的大件使用）。

## 3. 署名与致谢（义务清单）

CC BY-NC 4.0 的署名义务按物种粒度履行：

1. `tools/fetch-assets.mjs` 抓取时**同步保存**每个物种的 `credits.txt`，并拷贝仓库根目录的
   `credit_names.txt`（作者 ID→名字/联系方式）到 `assets/credits/`；
2. 图集 manifest 记录每个物种的作者列表（解析 credits.txt 中标为当前版本的行）；
3. 游戏内"制作与署名"页（Esc 菜单入口）：SpriteCollab 与逐物种作者滚动列表 + 链接；
4. 仓库 `CREDITS.md`：来源、许可、作者汇总表；
5. 页脚常驻一行：素材来自 SpriteCollab/PokeAPI 社区图库，Pokémon © Nintendo/Creatures/Game Freak。

## 4. 素材管线（tools/）

```
fetch-assets.mjs（node 22 自带 fetch）
  输入: 《04》名单 + manifest（锁定 SpriteCollab commit 哈希）
  1. 拉 tracker.json → 逐物种核对动作完备度（Idle/Walk/Attack/Hurt/Faint 或替代方案）
  2. 下载 sprite/<4 位号>/ 的 <动作>-Anim.png / -Offsets.png / -Shadow.png + AnimData.xml + credits.txt
     （raw.githubusercontent.com/PMDCollab/SpriteCollab/<commit>/...，8 并发 4 重试，同 gym-pixel）
  3. 下载 portrait/<4 位号>/Normal.png、闪光变体、PokeAPI 道具图标与叫声
  4. 校验：尺寸为偶数、AnimData 帧数 × 行数与图集格数一致；原始件放 .cache/（不入库）

pack-atlas.py（Python + Pillow，产物入库）
  1. 解析 AnimData.xml：FrameWidth / FrameHeight / Durations[] / ShadowSize / CopyOf /
     RushFrame / HitFrame / ReturnFrame
  2. 按行切帧（行序 Down, DownRight, Right, UpRight, Up, UpLeft, Left, DownLeft，共 8 行；
     单行动作保持 1 行）；Offsets.png 的绿色像素=身体中心（实体锚点），Shadow.png 的白色像素=影子中心
  3. Durations 单位是 1/60 秒 → 直接生成动画时间轴；HitFrame 用来对齐出弹/命中时刻；
     ShadowSize（0/1/2）决定假阴影椭圆大小
  4. 打包：每物种一张 ≤2048² 图集 + JSON 索引（帧矩形/锚点/时长）；全部最近邻、不缩放
  5. CopyOf 动作直接引用原帧区域（不支持链式引用，与上游一致）

check-anim.mjs
  按《04》名单输出动作完备度报告（✅/⭕/缺哪些），作为名单定稿依据
```

**版本纪律**：manifest 锁 SpriteCollab commit 哈希；重抓=换哈希+全量回归，防止上游改动悄悄改变素材。

## 6. 下架预案（takedown plan）

1. 触发：收到权利方/平台通知，或社区可靠信源报告执法动向；
2. 动作（24 小时内）：在仓库设置里关闭 GitHub Pages → 仓库转私有（免费账户的私有仓库没有 Pages，
   等于彻底下线）→ 社群渠道（若有）公告；
3. 存档：玩家存档在 localStorage（本机，不受下架影响）；M4 提供"存档导出 JSON"功能；
4. 复活路径（ADR-15）：素材层整体切原创怪包（约 40 只原创像素怪 + CC0 全套）→ 更名重新上线，
   引擎/数值/生成算法 100% 复用——**M4 结束时做一次换皮桌面推演，验证 48 小时承诺**。
