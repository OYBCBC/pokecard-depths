# 01 · 游戏设计文档（GDD）

> 《宝可梦·晶穴深处》Pokémon: Crystal Depths —— 以撒式动作肉鸽 × 宝可梦 × HD-2D
> 版本 v0.1（M0 立项稿）· 2026-11-02

## 1. 概述

### 1.1 一句话

> 带着皮卡丘下洞窟：走进水晶迷宫，用招式轰开蜂拥的野生宝可梦，捡起技能机和树果滚雪球，
> 打倒把守各层的道馆馆主，最深处等着你的是梦幻。

### 1.2 灵感坐标系

| 来源 | 借什么 | 不借什么 |
| --- | --- | --- |
| 《以撒的结合·忏悔》 | 房间制地牢、清怪开门、道具构筑、商店/宝箱/恶魔房节奏、隐藏房、数值公式 | 身体恐怖题材、宗教意象、劝退式的上手难度 |
| 《宝可梦》正作 | 属性克制 18×18、STAB、种族值、进化链、官方道具与树果命名 | 回合制、精灵球捕捉流程（同伴靠救援营地结伴） |
| 《八方旅人》HD-2D | 像素精灵×3D 灯光的立体绘本感、景深、点光、粒子 | 回合制/横版站位战斗、JRPG 叙事结构 |

### 1.3 目标玩家与体验目标

- 玩过以撒/元气骑士/吸血鬼幸存者的宝可梦粉丝；单局 20–35 分钟；
- 三条体验支柱：①每局地图与道具都不同（重开成本低）②走位躲弹的紧张感（操作有上限）
  ③"这个道具组合居然能这样"的顿悟时刻（构筑深度）；
- 传播目标：跑动走位、道具组合、Boss 战瞬间的短视频名场面（HD-2D 灯光就是为截图/录屏而生）。

## 2. 核心循环

```
        ┌────────────────────────── 单局（Run）──────────────────────────┐
        │                                                                │
  选同行宝可梦 → 进入第 1 层 → 【房间循环】 → 层 Boss（馆主）→ 下一层    │
        │                    清怪 → 开门 → 选门 → 下一房间                │
        │                    拾取金钱/道具 → 商店/宝箱/事件房              │
        │                    （受伤/回血资源管理贯穿始终）                  │
        └──────────────── 死亡或通关 → 图鉴/成就/解锁 → 下一局 ────────────┘
```

**单房间循环**（本作的心跳，约 15–40 秒/房）：进房 → 门封 → 刷怪波（1–2 波）→ 清完开门 →
拾取掉落（钱/心/道具）→ 看小地图选下一个门。

**单局结构**：3 层（首发），每层 8–16 个房间（越深越多，公式见《02》§6），层 Boss=道馆馆主；
击败第 3 层馆主后走楼梯进入第 4 层"晶核之间"（迷你层：4 房，直奔 Boss）迎战梦幻（M5 已落地）。

## 3. 操作与手感

| 输入 | 行为 |
| --- | --- |
| WASD / 左摇杆 | 移动（8 方向，速度见 §4） |
| 鼠标 / 右摇杆 | 瞄准方向 |
| 鼠标左键 / RT | 发射当前招式（按住连发，射速=出招速度） |
| 空格 / LT | 冲刺（0.18s 位移+无敌帧，充能 2 层，1.2s/层；可撞开有裂纹的墙） |
| Q / 滚轮 / 手柄 Y | 切换技能槽 A/B（B 槽装填技能机后启用） |
| E / 手柄 X | 使用树果/消耗品（1 槽） |
| R / 手柄 RB | 释放 Z 招式（PP 满 100） |
| F / 手柄 LB | 换替补同行宝可梦（有替补时） |
| Tab / Select | 全屏地图 |
| Esc / Start | 暂停（道具栏/图鉴/署名页） |

**手感三件套**（不可裁剪的验收项）：命中停顿 hit-stop（60–90ms）、受击震屏、命中闪白+击退。
首发帧预算内必须全部实现——HD-2D 画面再好，手感烂就全盘皆输。

**冲刺设计**：以撒没有冲刺，本作加入是因为宝可梦素材的"高速移动"心智 + 俯视角弹幕密度
需要应急位移；充能 UI 在脚底（两格圆点），避免 HUD 占屏。

## 4. 玩家属性（以撒六维 × 宝可梦转译）

玩家=训练师（不站场的纸片人），实际战斗属性挂在当前**同行宝可梦**上：

| 以撒术语 | 本作术语 | 初始值 | 说明 |
| --- | --- | --- | --- |
| Health | **亲密度** | 6 格（3 颗大心） | 受击 -1 格（高攻敌人 -2 格）；大心=2 格；不做魂心等变种 |
| Speed | 移动速度 | 1.00 | 下限 0.1、上限 2.0（以撒同款硬上限） |
| Tears | 出招速度 | 2.73 发/秒（约每 22 帧@60fps 一发） | 公式见 §8.3 |
| Damage | 特攻 | 3.50 | 成长公式见 §8.2 |
| Range | 射程 | 6.5 格 | 弹体飞行该距离后消散 |
| Shot Speed | 弹速 | 1.00 | 弹体移速系数 |
| Luck | 运气 | 0 | 影响掉落判定（§9.1）与暴击率（§8.2） |
| ——（新增） | **PP 能量** | 开局 0，上限 100 | 造成伤害积累，满了按 R 放 Z 招式 |

**Z 招式（大招）**：每只宝可梦 1 个专属全屏/爆发技（皮卡丘=十万伏特全屏链电），
PP 满 100 释放，是"名场面制造机"与逆风翻盘阀。PP 积累 = 造成伤害 × 0.25（克制命中再 ×1.5），
约 2–3 个房间放一次（系数入 balance.json）。设计上等价于以撒的主动道具位，
但绑定宝可梦（换宝可梦=换大招，见 §6）。

## 5. 攻击与属性系统

### 5.1 弹体=招式

普攻=宝可梦的本系招式弹（皮卡丘=电击直线弹）。弹体判定四类原语（继承可行性报告的判定原语）：
直线弹（projectile）/ 扇形近战波（sweep）/ 圆形脉冲（pulse）/ 自身光环（aura）。

### 5.2 属性克制作用于伤害

敌方野生宝可梦有属性；玩家招式弹有属性；伤害乘以**官方 18×18 克制表系数**（×2 / ×0.5 / ×0，
双属性相乘可达 ×4 / ×0.25）。

- 克制命中：黄色飘字+更大的击退+额外 PP；
- 被免疫（×0，如地面系免疫电）：弹体被弹开粒子，教学"换属性打"；
- STAB：招式属性=宝可梦属性时 ×1.5（正作规则照搬）。

克制表是本作构筑深度的第一根支柱：满房小拳石/大岩蛇（岩/地面）时，电招式无效、
水招式 ×4——该换技能机了。

**防卡关规则**（皮卡丘打小刚是动画名场面，也是设计陷阱；M4.5 起全面化）：
①**全部敌人**的 ×0 免疫一律按 ×0.5 结算——克制体系的强弱差距保留（×0.5 仍明显刮痧），
但任何构筑永不锁死；②**出生房免费技能机三选一**（水/火/草）——B 槽（Q 切换）开局必有，
免疫属性的构筑出口每局拿得到；③**救援营地每层保底**——替补按 F 上场时 A 槽与 STAB
整体换成替补的属性和招式（换宠=换 Build 载体），是打克制的战略资源。

### 5.3 双技能槽

A 槽=本系弹（默认），B 槽=可替换的副招式（拾取技能机装填，同时只带 1 个，新的替换旧的）。
技能机决定 B 槽的属性、威力与**弹道原语**——换弹种就是最基础的构筑动作。
M4.6 起：技能机带可学性（learn 表，贴正作：皮卡丘学得会打草结/燕返，学不会水枪），商店/
宝箱/掉落只出当前搭档可学的；弹道原语升级为以撒式攻击方式——三重攻击（3 发扇形）、
燕返（强追踪）、破坏光线（贯通大炮·攻速 ×2.6）；开局三选一按物种定制（§11）。

## 6. 同行宝可梦（换宠=换 Build 载体）

- **开局三选一**：皮卡丘（均衡·电）/ 小火龙（高伤低容错·火）/ 杰尼龟（弹速射程·水）——
  熟悉的初始搭档心智，三种初始手感；另有 3 只解锁角色（§11）；
- **进化**：达成条件（楼层进度+特定道具）后宝可梦进化——立绘/动画换成进化形态，
  面板大幅成长+大招升级（皮卡丘→雷丘：十万伏特→打雷）。进化等价以撒的"变身"时刻，
  全屏演出（灯光脉冲+慢镜）；
- **救援营地与替补**（每层保底一个营地房）：3 只受困的野生宝可梦三选一结伴同行
  （没有精灵球捕捉流程），成为替补；按 F 秒换（换人瞬间无敌 0.5s）。**M4.5 起替补上场
  = 换 Build 载体**：A 槽招式与 STAB 属性整体切换为替补的（主属性映射到可用招式表，
  如蚊香蝌蚪上场放泡沫·水 STAB），B 槽技能机照常可用——皮卡丘打不动岩石系时换水系替补，
  是打克制的第一战略资源；
- **亲密度叙事**：受击扣的是"亲密度"——归零=宝可梦体力不支、被护送撤退，本局结束
  （不出现训练师挨打等暴力画面，贴合宝可梦 IP 调性）。

## 7. 道具系统（构筑深度主战场）

**命名原则**：道具优先采用官方道具名，效果做"动作游戏化转译"——木炭=火招式 +20% 与官方一致；
讲究眼镜=特攻 ×1.5 但锁定招式，保留官方的取舍感。没有合适官方原型的标注"原创"。
粉丝一眼认得、再一想"原来这么转译"，就是第二层乐趣。

### 7.1 四类道具

| 类型 | 以撒对应 | 例子 | 槽位 |
| --- | --- | --- | --- |
| **被动道具** | passive item | 技能机（装填 B 槽弹种）、木炭（火伤 +20%+灼烧）、磁铁（电伤 +20%）、讲究眼镜（特攻 ×1.5 但锁定 A 槽） | 无限 |
| **强化道具** | stat up | HP增强剂（亲密度上限 +1 大心）、特攻增强剂（伤害提升值 +1）、速度增强剂（移速 +0.15）、PP提升剂（大招充能 +25%） | 无限 |
| **消耗品** | active / pill | 文柚果（回 2 格，CD 45s）、木子果（净化异常，CD 25s）、神奇糖果（一次性：进化进度 +50%） | 1 |
| **纪念品** | trinket | 剩饭（每清一房回 0.5 格）、气势披带（满亲密度时免死一次/层）、护符金币（金钱 +25%） | 1（丢弃替换） |

### 7.2 道具池与稀有度

每件道具标 0–4 级品质（以撒同款五档）；池按房间类型分：
`普通池 / 宝箱房池 / 商店池 / 黑市池 / 祭坛池 / 隐藏房池`。同池不重复抽取；局内已拥有的
互斥道具不再出现。首发道具总量约 70 件（被动 42 / 强化 8 / 消耗品 10 / 纪念品 10），
另有馆主徽章 3 枚；M3 前先交付 30 件开测，见《04 内容清单》。

### 7.3 协同（Synergy）设计法

每件被动道具只做**一个清晰可读的效果**（+数值 / +机制标签），复杂效果由标签叠加涌现：
`灼烧标签×分裂标签=分裂弹也带灼烧`、`弹射标签×追踪标签=绕墙追击`。道具描述用一句话+图标标签，
不写数值论文。设计时每件道具登记：标签（0–2 个）、互斥项、品质。

### 7.4 恶魔房转译：火箭队黑市

清房不受伤累积"黑市计量条"（对应以撒恶魔房几率：基础 1%、Boss 战无伤 +35%、整层无伤 +99%）。
计量条在下一层生成时检定：达标则把一个剩余死端设为**火箭队黑市**——用**亲密度上限**交易高级道具
（上限 -1 大心换品质 3+ 道具），以撒恶魔交易同款"舍身换强度"的构筑分岔点。
对应地，**吉利蛋祭坛**（=天使房）用金钱捐献换回复/守护类道具——善良路线。
**进过黑市则本局祭坛不再出现**（以撒恶魔/天使互斥同款）。

## 8. 数值框架

### 8.1 双轨制原则

```
敌人轨（种族值 → 房间战面板，老玩家看种族值就知道谁难缠）：
  HP       = 2 + HP种族值/8          （保留 1 位小数；小拉达 30 → 5.8，杂兵落在以撒 3–10 区间）
  接触/弹伤 = 1 格；攻击或特攻种族值 ≥100 者 = 2 格（耿鬼、穿山王、三合一磁怪等）
  移速     = 0.5 + 速度种族值/100     （小拉达 72 → 1.22，与玩家初始 1.0 同标尺）
  特防修正 = clamp(sqrt(70 / 特防种族值), 0.6, 1.4)
             玩家招式全部按"特殊招式"结算，所以看特防：大岩蛇防御 160 但特防只有 45，
             被打反而疼——种族值心智完整保留，还藏了个彩蛋
玩家轨（以撒六维）：特攻面板 D 按以撒公式成长（§8.2），射速按 §8.3
单发伤害 = D × (招式威力/40) × 克制 × STAB × 特防修正 × 暴击
           威力取官方值：电击/水枪/火花均为 40 → 系数 1.0；技能机招式按各自威力
Boss HP  = 设计手填（不走换算，见 §8.4 锚点）
```

### 8.2 特攻成长（以撒 Repentance 官方公式移植）

```
特攻面板 D = 3.5 × sqrt(Σ伤害提升值 × 1.2 + 1) + Σ固定加值     —— 连续 +攻 收益递减
例：一个 +1 道具 → 3.5 × sqrt(1×1.2+1) = 5.19
暴击：基础 0%，焦点镜 +10%，每点 Luck +1%；暴击 ×1.5（以撒无暴击，此为宝可梦向新增）
伤害保留小数（以撒同样是小数伤害），不取整
```

### 8.3 出招速度（以撒 Repentance 官方 fire delay 公式移植）

```
delay  = 16 − 6 × sqrt(1.3×T + 1)     T=Σ射击加速值，可为负（惩罚道具）
出招/秒 = 30 / (delay + 1)            T=0 → delay 10 → 2.73/s（初始值即由此而来）
软上限：T≈1.82 → delay 5 → 约 5/s；再往上收益锐减（以撒同款天花板）
```

### 8.4 敌人波次与房间难度预算

每房难度点数=Σ敌人分值；分值=威胁系数（伤害+弹速+血量档）× 金冠倍率（金冠 ×2，对齐以撒 Champion 双倍血）。
层 N 普通房预算 = 6 + 2N。**金冠率**：普通难度 5% → 8% → 11%（层 1–3；以撒 Normal 基础 5%），
困难 ×2.5（12.5% → 20% → 27.5%；以撒 Hard 基础 20%），深渊 40%。

**血量锚点**（对齐以撒首章，直接决定手感）：杂兵 3–10（以撒 Fly 3 / Pooter 8 / Gaper 10），
层 1 Boss 200–300（以撒 Monstro 250），后续层 Boss ≈ 350 / 500。用 `tools/sim.mjs`
机器人模拟（前两作同款方法）校准 TTK（time-to-kill）目标：普通房 8–20s、强敌房 25–40s、Boss 45–90s。

## 9. 敌人与 Boss

### 9.1 敌人原型（AI 行为族）

| 族 | 行为 | 以撒原型 | 首发代表 |
| --- | --- | --- | --- |
| 冲撞族 | 直线扑击，撞墙硬直 | Charger / Gaper | 小拉达、超音蝠、小拳石（滚动） |
| 游走族 | 随机走+接触伤害 | Fly | 绿毛虫、鬼斯（穿墙） |
| 射手族 | 定点朝玩家吐弹 | Pooter | 走路草（溶解液）、小磁怪（电击）、蚊香蝌蚪（水枪） |
| 自爆族 | 靠近自爆 | Boom Fly | 雷电球、瓦斯弹（毒雾范围） |
| 掠夺族 | 偷钱/抢掉落 | Greed（偷钱） | 喵喵（聚宝功）、变隐龙（隐形伏击） |
| 分裂族 | 死后分裂 | Envy（分裂） | 臭泥（死后裂成两只小臭泥，留毒地面） |
| 领主族 | 光环增益周围敌人 | —（本作新增） | 大嘴蝠（吸血光环） |

- **强敌**：各层常规敌的进化型（拉达/大嘴蝠/顽皮雷弹/三合一磁怪/穿山王/耿鬼），分值高，层中后段出现；
- **金冠**：任意敌人的精英变体（以撒 Champion 同款）——体型 ×1.3、HP ×2、附加 1 个特性
  （弹幕环/冲刺/召唤），出现率见 §8.4；
- 状态异常（灼烧/麻痹/中毒/冰冻）按官方心智 tick 结算，可被玩家附加也可反噬。

> 掉落判定参照以撒房间清空奖励模型：`roll = rand + Luck×0.1`，按区间映射到
> 无掉落/钱/心/树果/钥匙/宝箱（以撒基准：22% 无掉落、5% 宝箱；比例入 balance.json）。

### 9.2 层 Boss = 道馆馆主

馆主登场=专属演出（聚光灯+台词条+王牌宝可梦登场叫声）。战斗=两阶段：

| 层 | Boss | 王牌 | 一阶段 | 二阶段（HP<50% 触发一次） |
| --- | --- | --- | --- | --- |
| 1 | 小刚 | 大岩蛇 | 钻地突袭+落石弹幕 | 石雨全屏+地形裂隙 |
| 2 | 马志士 | 雷电球军团 | 电网矩阵+追踪球 | 全屏放电（躲掩体节奏） |

## 11. 元游戏与进度

- **图鉴**：本作遭遇过的宝可梦（含金冠变体图标）——跨局持久化，点击播叫声；

  新开局宝可梦（初始三选一之外的解锁角色：伊布/卡拉卡拉/蚊香君，各自不同初始面板与招式）；
- **挑战码与种子**：每日挑战种子+分享码（前缀 `DPT1.`，编码楼层/种子/成绩），本机榜起步，
  云榜沿用 gym-run 的 API 方案（serve.py 部署处生效，Pages 静态降级本机榜）；
- **难度阶梯**（M5 已落地）：普通 → 困难（敌血 ×1.3·预警 ×0.88）→ 深渊（敌血 ×1.7·馆主血 ×1.5·预警 ×0.78）；搭档选择页选难度，每日挑战固定普通，榜单记难度。
