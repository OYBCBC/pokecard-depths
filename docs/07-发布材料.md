## 4. GIF 重录流程（备忘）

1. `python3 tools/serve.py 8349`；浏览器开 `http://127.0.0.1:8349/?debug&nosw=1`（720p）
2. IAB evaluate 布置场面：`__depths.restart()` → `goRoom(房)` → 改状态（pp=100 等）
3. 循环 `pump(5)` + `tab.screenshot()` 落帧到 `.tmp-frames/<名>/`（每批 ≤10 帧防 30s 超时；
   键盘触发用 keydown+keyup 配对 dispatch——pump 的帧内会消费）
4. PIL：480×270 resize → 64 色 MEDIANCUT 量化 → 12fps GIF（`save_all + duration=83`）
