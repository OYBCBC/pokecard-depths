# 03 · 美术与视觉规范（HD-2D 配方）

> 《宝可梦·晶穴深处》视觉规范 · v0.1（M0）· 2026-11-02
> 本文是"HD-2D 到底怎么调出来"的操作手册：参数给初值，验收给标准。
> 技法来源：Acquire《八方旅人》Unreal Fest East 2018 讲座与 4Gamer 访谈、Octopath II 开发者访谈、
> 社区复刻实践（Unity 复刻笔记、three.js 的 Marcel328/hd2d 等）交叉验证；
> 没有一手出处的数值一律标注"本项目初值"，M1 起实测调整。

## 1. HD-2D 的定义（本项目语境）

像素精灵面片（2D）站进实时光照的立体场景（3D），再套摄影机后期（景深/泛光/调色）。
**一句话验收**：截图发到群里，得到"这是 3D 的？不对，这是像素的？也不对……"的反应。

八方旅人团队自述的关键做法：像素素材严格贴合像素网格、特效生成时附带点光让精灵在环境里投下影子、
按场景用脚本调景深/调色/晕影。社区复刻补充了可执行的数值（见 §5、§7）。

## 2. 尺度与像素一致性（一切的地基）

| 规则 | 值 |
| --- | --- |
| 世界单位 | 1 tile = 1.0 世界单位 |
| 纹素密度 | **16 texel / 世界单位**（全场恒定：地板、墙面、精灵同密度；Marcel328/hd2d 同取 16） |
| 采样 | 放大 `magFilter=NearestFilter`（保持硬像素）；地板/墙面缩小 `minFilter=NearestMipmapLinearFilter` + 各向异性 4–8（斜视远处防摩尔纹闪烁）；精灵面片基本不缩小，用 `NearestFilter` |
| 精灵帧尺寸 | 按 PNG 原尺寸 ÷16 换算世界尺寸（皮卡丘 Walk 帧 32×40px → 2.0×2.5 单位，帧内含留白，实际身高约 1.5 格） |
| 贴图上限 | 单张 ≤2048²；远近大小靠相机透视，不靠缩放纹理 |

**像素一致性守则**：任何新素材先问"折算回 16 texel/unit 是否整数对齐"；错位的素材宁可重做也不留例外
（对齐失败=行走时像素"呼吸抖动"，是 HD-2D 最常见的翻车点）。

## 3. 相机（固定舞台感）

| 参数 | 初值 | 说明 |
| --- | --- | --- |
| 视角 | PerspectiveCamera **fov 40**（竖直） | 窄视角=舞台压缩感（本项目初值） |
| 俯角 | **-55°**（绕 X 轴），偏航固定 0（不旋转） | 全程锁死：HD-2D 的空间感来自"永远以同一个斜俯角看舞台" |
| 跟随 | 玩家位置 lerp 0.08 + 移动方向前瞻 0.8 单位 | 战斗圈始终略偏屏幕下方 1/3 |
| 演出 | Boss 登场推近（fov 40→34，0.6s ease）；进化时 fov 脉冲 | 只动 fov 与位置，不转俯仰 |
| 景深 | 对焦距离=相机到玩家的距离，玩家前后 ±2.5 单位清晰，前景/背景虚化 | 参数见 §7 |

移动端窄屏：fov 提到 48，保证横向战斗圈完整可见。八方系列没有公开相机角度数值，以上全部是本项目初值。

## 4. 灯光配方（每楼层一套"摄影棚"）

| 光 | 参数 | 作用 |
| --- | --- | --- |
| HemisphereLight | 天光=楼层主题色 0.55 / 地面反光暖灰 0.35 | 底色情绪 |
| DirectionalLight | 强度 1.1，方向 (-2, 3, -1.5) 归一化，暖白 | 主投影光；阴影正交盒覆盖整个房间、固定不动（《02》§7.3） |
| 点光池 ×8 | 距离 4–6，衰减 2，暖橙/主题色 | 火把、水晶、大招、掉落高亮；"特效带点光"是八方团队的做法 |
| Emissive | 水晶 2.2 / 敌弹 3.0 / 特效 2.5 | 只有这几类喂 Bloom，防止全屏发光发糊 |

楼层色板（三主题）：

## 5. 精灵面片（含阴影，最关键工艺）

1. **面片而非 Sprite**：`PlaneGeometry` 网格，只绕 Y 轴转向相机；`THREE.Sprite` 不进阴影 pass，禁用；
2. **alphaTest=0.5 + DoubleSide**：走不透明管线（写深度），后处理（DoF/Bloom）才不会在精灵边缘出错；
3. **投影**：`castShadow` + `customDepthMaterial`（贴图+alphaTest+RGBA 深度打包）；点光下额外
   `customDistanceMaterial`；双面投影让精灵影子是"人形"而不是一道细缝（Unity 复刻笔记的 Two Sided 投影同理）；
4. **法线朝天倾斜**：面片法线从"正对相机"改为向天顶方向抬约 **60°**（本项目初值）——平行光在精灵上
   打亮上半身、压暗下半身，"像素人被灯照亮"的错觉全靠它（Marcel328/hd2d 同法）；
5. **脚下接触**：椭圆假阴影（半透明黑 0.35，大小取 AnimData 的 ShadowSize 0/1/2，跳跃/击飞时缩放）
   + 真实投影并存——真影负责"站在场景里"，假影负责"贴地读位"，两者缺一不可；
6. **8 方向动画**：PMD 图集行序 Down / DownRight / Right / UpRight / Up / UpLeft / Left / DownLeft，
   按移动向量八向量化取行；Idle 按 AnimData 的帧序循环；帧时长读 AnimData.xml（单位：1/60 秒）。

## 6. 场景件

- **墙体**：实心 3D 体块（高 0.8 单位）+ 像素图块纹理，投影也受影——"墙是 3D 的、人是面片"制造层次；
- **地板**：整房一张面（17×11 单位），16px CC0 图块拼贴；洞窟层加顶点色暗角（中心亮、四角暗 15%）；
  发电厂层水坑=镜面反射贴片（同时把"导电机关"可视化）；
- **装饰**：水晶簇=低模+高 emissive+点光；草丛=小面片摆动（顶点 shader 相位波）；浮尘粒子常驻（§8）；
- **门**：开=拱形发光洞（主题色 emissive 1.5）；封=闸门体块落下+"咔"一下震屏。

## 7. 后处理参数表（初值，M1 起逐档调）

| 效果 | 参数 | 参考 |
| --- | --- | --- |
| DoF（景深） | 玩家前后 ±2.5 单位清晰，前景虚化强、远景弱 | Unity 复刻笔记：光圈开到最小、对焦主体；Marcel328 的"清晰平台带" |
| Bloom | mipmapBlur，threshold 0.9，radius 0.85，levels 8 | pmndrs 默认结构；Unity 复刻用 2.5/0.6 偏亮，本项目只让 emissive 发光 |
| ToneMapping | **AgX**（three r160+ 内置曲线，pmndrs ToneMappingEffect 支持） | 高光滚降柔和，适合 HDR 点光 |
| 调色 | 每楼层一张 32³ LUT（离线调好导出，LUT3DEffect 加载） | 八方用 UE Color Grading 按场景脚本化 |
| Vignette | 0.35 | Unity 复刻用 0.536 偏重，本项目取保守值 |
| 颗粒 | Noise 0.02（仅高档） | 抵消大面积渐变色带 |
| 抗锯齿 | SMAA（像素风禁用 TAA 类时域模糊） | — |

**色彩管线**：`outputColorSpace=SRGB`，线性 HDR 工作流（HalfFloat 中间缓冲），链末端 AgX+LUT 输出。

## 8. 粒子与特效（表现力的杠杆）

- 浮尘/萤火：30×30 单位盒内 40 粒，慢速漂浮，alpha 60%——HD-2D 的空气感（盒尺寸与透明度取自 Unity 复刻笔记）；
- 命中：8–14 粒受击色碎屑 + 1 次白闪（材质 emissive 0→1→0，共 80ms）+ 击退；
- 克制命中：黄色大字+额外 4 粒星形；被免疫：灰字+"叮"弹开粒子；
- 光柱：Boss 房/道具房顶部体积光贴片（挂在相机下，永远朝镜头）；
- **规则**：战斗读位类特效（弹、预警圈、命中）**永远自发光、不受景深模糊**——可读性优先于美感。

## 9. UI 与字体

- HUD 用 DOM+CSS 叠加（不进 three 场景），缝合像素字体 12px 基准、`image-rendering: pixelated`；
- 图标（心/钱/钥匙/消耗品）：16×16 像素图标，整数倍缩放显示；官方原型道具用 PokeAPI 30×30 图标；
- 全屏道具卡：深色半透底 + 立绘 + 品质色边框（0 白 /1 绿 /2 蓝 /3 紫 /4 红金）；
- 伤害飘字：像素数字字体，白=普通/黄=克制/灰=免疫/红=受击，1.2 单位高、上飘后受重力回落。

## 10. Boss 演出与"名场面"清单（传播素材）

1. **馆主登场**：房间暗场 → 聚光扫过馆主名牌（徽章色剪影，不用人物立绘）→ 王牌宝可梦跳出+叫声+全屏震 → 灯光恢复（3.5s）；
2. **Z 招式**：镜头微拉、时间 0.3×，全屏属性色泛光脉冲 0.4s；
3. **进化**：白闪 2 帧 → 新形态+全屏波纹 → 恢复（1.5s，可跳过）；
4. **克制击杀**：慢镜 0.2× 0.5s + 闪属性色——短视频的天然切片；
5. **通关演出**：水晶核心碎裂，光柱冲顶，镜头拉远成"立体绘本盒"全景。
