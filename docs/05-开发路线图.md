## 1. M1 走路骨架（✅ 2026-11-03 完成）

任务：

1. `vendor/` 引入 three r187 + postprocessing 6.39.x（curl 从 unpkg/jsDelivr 拉固定版本 ESM 构建，
   版本写进 `vendor/VERSIONS`）；import map 骨架；
2. `gfx/renderer.js` 画质三档 + 自动判档；`index.html` 加载页（进度条 + 字体预载）；
3. 手工搭一个洞窟房（17×11）：CC0 图块地板 / 3D 墙体 / 火把点光 / 水晶 emissive / 浮尘粒子；
4. `assets/` 先只打包皮卡丘（Walk+Idle+Hurt）：fetch-assets → pack-atlas.py 跑通全管线；
   同时验证皮卡丘叫声的降级路径（该文件实为 MP3 数据，《06》§2.2）；
5. billboard 系统（《03》§5 工艺：alphaTest / 双面投影 / 深度材质 / 法线倾斜 / 假阴影）+ 8 方向动画驱动；
6. 相机跟随 + 输入层（先做键鼠）+ WASD 走路 + 帧插值；
7. 后处理链装配（DoF/Bloom/AgX/Vignette/SMAA）；
8. 试玩 PokéIsaac，写一页体验缺口笔记（《00》§六）。

验收：《03》§11 六项全勾；`?debug` 面板显示 fps/drawcall/实体数。

## 2. M2 战斗核心（✅ 2026-11-03 完成）

1. 弹体系统（四原语：projectile/sweep/pulse/aura）+ 弹×敌×墙碰撞；
2. 敌人三族（冲撞/游走/射手）+ 波次刷怪 + 房间状态机（封门/清空开门）；
3. 伤害结算：特攻成长（以撒公式）× 威力/克制/STAB/特防乘区（《01》§8），`test-combat.mjs` 全绿；
4. 手感三件套：hit-stop / 震屏 / 闪白击退；受击无敌帧 + 冲刺（充能 2 层）；
5. HUD v1（心/PP/金钱）+ 死亡→重开循环 + `?debug` 的 `skipTo`；
6. `sim.mjs` 雏形：机器人打 50 房输出 TTK。

验收：伤害飘字/克制黄字/免疫灰字可读；中档机型满屏弹幕不跌破 55fps。

## 7. 里程碑外常设事项

- **每周**：一次 `sim.mjs` 平衡报告（改数值必跑）；一次真机手感试玩记录；
- **内容排产**：新宝可梦/道具按《04》§8 检查单走，任何"顺手加的内容"必须过检查单才入池；
- **版本纪律**：vendor 锁版本；素材 manifest 锁 commit；每次 tag 附变更日志；
- **风险看板**（每个 M 评审一次）：
  - 视觉不达标 → M1 延长，砍 M5 打磨项来补；
  - 手感不佳 → M2 延长（最多 +2 周），触屏后移；
  - 素材覆盖缺口 → 按 check-anim 报告换名单（不动引擎）；
  - 竞品 PokéIsaac 快速迭代 → 坚持差异化三件套，不拼内容量；
  - 法律风险升级 → 执行《06》§6 预案，转原创包路线（M4 已推演过）。
