Debug 控制台手册

M11 · 与 招式靶场 / 游戏本体 同源 · 仅 ?debug 参数下启用，正式包零影响
打开方式：进入 游戏（?debug=true） 后按 `（反引号）呼出控制台； 触屏设备点右下角 ⌘ 按钮。每条命令执行后自动刷新房间视图。

一键直达（?auto= 深链）

跳 F4 幽冥层 梦幻终战 达克莱伊 裂缝房（超梦） 无敌 + 加速 + 满钱钥匙 M11-B 新 TM（实装后） 结局模拟（M11-C 实装后）

命令一览

命令说明
help [命令]命令列表 / 单条详细说明
stage <1-6>向前跳层（保留成长）。往回用 restart 层号
restart [层号]重开一局，可指定起始层
goto <房型>传送本层房型：boss / shop / treasure / challenge / secret / camp / blackmarket / altar / vault / fissure / forge / gacha / blood / gift / start / combat
boss <eid>直开 Boss 战：brock / surge / sabrina / agatha / mew / mewtwo / darkrai（进 boss 或裂缝房并强制 spawn）
fissure本层强制生成裂缝房（邻出生房）并传送——M11 起裂缝房按概率生成（F4 8% / F5 12% / F6 25%），测试超梦用这条
spawn <eid> [n]玩家周围刷敌（enemies.json 的 id，如 spawn gengar 3）
give <itemId>道具入包（kind 决定落位：passives / trinket / consumable / badges），如 give tm-hyper
take <itemId>移除一件已持有道具
killall全场 HP 清零——走正常死亡结算（Boss 奖励 / 徽章 / 结局分支都生效）
clear当前房直接置清（无死亡结算，看门/路线用）
heal / hp <n>回满 / 设置当前亲密度
pp <n> / ppfull设置 / 回满 PP
money <n> / keys <n>设置金钱 / 钥匙
god无敌切换（受击无效，弹「格挡」提示）
speed <0.25-4>模拟时间倍率（以撒 Debug 同款快进）
hudHUD 显隐（截图/录屏用）
seed打印种子 / 层 / 房 / 挑战码（可直接分享复现）
species <id>切换搭档（含未解锁：pikachu / eevee / cubone / poliwhirl / charizard / scizor / lucario / rayquaza…）
difficulty <normal|hard|abyss>局内切换难度三档
dex / achv图鉴全开 / 成就全开（立即写 localStorage）
win强制结算胜利（走结局演出）
ending <1-4>结局条件模拟（M11-C 终焉宝箱实装后生效）

行为约定

项说明
事件清空每条命令执行后清残留事件队列并重建房间——暂停期间 render 不清事件，不处理会重复演出
暂停控制台打开时模拟暂停（同图鉴/菜单）；关闭自动恢复。你手动暂停菜单时开控制台，关闭控制台不会顺带解除你的暂停
与 selfcheck 互斥?selfcheck 优先，控制台不注入——自动化回归不受影响
正式包无 ?debug 参数时控制台、⌘ 按钮、` 监听全部不注入，玩家不可见
